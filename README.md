# Bank Queue Simulation

## Overview

A discrete-event simulation project that models a bank service system using Microsoft Excel.

The simulation represents customer arrivals, waiting queues, and cashiers, and evaluates how different system configurations affect overall performance.

## Objectives

- Simulate customer arrivals and service processes.
- Model waiting queues and cashier availability.
- Compare different bank configurations.
- Analyze system performance using key simulation metrics.

## Scenarios

The project includes three configurations:

- **Base Case** — Current system configuration.
- **Scenario A** — Modified system configuration.
- **Scenario B** — Alternative configuration.

Each scenario is modeled separately in the Excel workbook.

## Performance Metrics

The simulation tracks:

- Waiting Time
- Queue Length
- Cashier Utilization
- Customers Served

## Tools

- Microsoft Excel
- Discrete-Event Simulation

## Project Structure

The Excel workbook contains the simulation models, parameters, calculations, and visualizations for all scenarios.
